# Computational Porous Media Group

Site do grupo, publicado em https://feraul.github.io

## Como editar

Todo o conteúdo fica em **`data.js`**. Para mudar um texto, uma publicação,
a equipe ou as bolsas, abra esse arquivo aqui no GitHub, clique no lápis
(Edit), faça a mudança e clique em **Commit changes**. Em um ou dois minutos
o site está atualizado. Não há nada para instalar nem para rodar.

- Apagar um item é apagar o bloco entre `{` e `}` (com a vírgula depois).
- Adicionar é copiar um bloco, colar abaixo e trocar os textos.
- Uma lista vazia, como `staff: []`, faz a seção sumir do site e do menu.
- Imagens novas vão na pasta `images/`, pelo botão **Add file > Upload files**.

## Arquivos

| Arquivo      | Para que serve                         |
|--------------|----------------------------------------|
| `data.js`    | Todo o conteúdo do site                |
| `index.html` | Visual e funcionamento (não precisa mexer) |
| `images/`    | Figuras                                |
| `.nojekyll`  | Diz ao GitHub para publicar sem processar |
